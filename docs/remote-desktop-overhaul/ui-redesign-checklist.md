# pb-mapper UI 重设计实现清单

2026-11-07

远程桌面交互重设计已确认，按[设计稿](design/README.md)实现。同一轮还要做两件事：图标统一成一套 Lucide（远程桌面新增 19 个、改 3 个），并修掉标题栏窗口按钮挤在内容页圆角上的问题。

PR #51 仍因流畅度阻塞合并，性能修复见[远程桌面流畅度优化优先级（借鉴 RustDesk）](perf-priorities.md)。UI 重设计可以与性能修复并行，标题栏修正和图标统一不依赖远程桌面，可以先单独发。

## 已确认的远程桌面设计

桌面端把管理集中在一页、查看时画面占满窗口；手机端画面优先，控件放进两侧留白。交互参考了 RustDesk，视觉沿用 POCOX。

| 区域 | 设计 | 画板 |
| --- | --- | --- |
| 信息架构 | 桌面侧栏新增“远程桌面”，共 6 个入口；手机底栏加“远程”，日志移入设置 | Main、MobileHome |
| 主机共享 | 一个“开启远程控制”按钮加三步说明；权限两档；邀请可复制或显示二维码；辅助服务、服务名、撤销放进“更多” | HostSetup、Main |
| 远程电脑列表 | 记住的电脑带在线状态和上次路径；正在查看的那台显示“回到画面” | Main、MobileHome |
| 添加电脑 | 桌面粘贴邀请并显示识别出的主机；手机以扫码为主、粘贴为辅；“记住此电脑”默认打开 | AddComputer、MobileAdd |
| 桌面查看器 | 隐藏侧栏；浮动工具栏可固定或收起成顶部把手；“显示”“快捷键”菜单；连接状态叠加在画面上 | Viewer、ViewerStates |
| 手机查看器 | 横屏时控件放在 16:9 画面两侧留白；触控板模式默认；键盘上方有修饰键条，右上角有小地图 | MobileViewer、MobileKeyboard |
| 手势 | 与 RustDesk 一致：轻点左键、长按右键、轻点两下按住拖拽、三指上下滚动、双指移动或捏合调整画面；直接触摸可开虚拟鼠标 | MobileGestures |

现有手势会变：右键从“双指轻点”改为“长按”，拖拽从“长按后移动”改为“轻点两下按住移动”，发布说明里要写明。

双指缩放和平移保持为纯本地操作：只改画面的缩放和偏移，不通知主机，不改画质或分辨率，弹出键盘时也不重置。小地图同样只改本地变换。依据和验收见[性能文档](perf-priorities.md)的“P1：缩放与平移只在本地”。

## 图标重设计

继续用 Lucide：项目里的 `lucide_icons_flutter` 3.1.25 已包含全部需要的图形，并提供 100–600 六种粗细。这次要做的是全应用统一一套、小尺寸加粗、补齐远程桌面一组。全部图形见设计稿的“图标系统”画板，那里用的就是这个包自带的字体。

- **只用 AppIcons。** 窗口按钮（`Icons.remove`、`crop_square`、`filter_none`、`close`）和 PR #51 远程桌面页面里的 Material Icons（`screen_share_outlined`、`keyboard_outlined`、`ads_click`、`mouse_outlined`、`pan_tool_outlined`、`desktop_windows_outlined` 等）全部换掉。
- **粗细跟着尺寸走。** 20 px 及以下用 400；24 px 及以上用 300。现在 `ui/lib/src/theme/app_icons.dart` 全部是 300，20 px 时线宽只有约 1.25 px，侧栏里发灰。做法：AppIcons 默认改用 400，空状态和大图块等少数 24 px 以上的位置另设 300 常量。
- **四档尺寸。** 16 标签与行内、18 按钮与菜单、20 侧栏与底栏、24 空状态与图块。
- **颜色跟着文字。** 状态靠彩色圆点表达，只有“这台电脑”和正在传输的隧道用蓝色。

| 含义 | 现状 | 改为 | 原因 |
| --- | --- | --- | --- |
| 隧道 | `cable` | `route` | `cable` 像电源线；`route` 表达两端之间的通路 |
| 中继在线 | `wifi` | `cloud` | `wifi` 容易被理解成本机 Wi‑Fi |
| 中继离线 | `wifi-off` | `cloud-off` | 同上 |
| 远程桌面入口 | 无 | `monitor` | 新的侧栏与底栏入口 |
| 远程桌面操作（19 个） | Material Icons | `screen-share`、`screen-share-off`、`monitor-smartphone`、`eye`、`mouse-pointer-2`、`keyboard`、`command`、`mouse`、`touchpad`、`pointer`、`qr-code`、`scan-qr-code`、`maximize`、`pin`、`power`、`shield-check`、`lock-keyhole`、`gauge`、`smartphone` | 与应用其余部分同一套 |
| 窗口按钮 | Material Icons 15 px | 自绘 10 px、1 px 线 | 与 Windows 原生按钮一致 |

应用启动图标和托盘图标不在这次范围内。

## 待修问题：标题栏窗口按钮与内容页边缘重叠

Windows 上，关闭按钮挤在内容页右上角。它离内容页边缘 8 px，内容页离窗口边缘也只有 8 px，按钮、18 px 圆角和两层边线叠在同一处，看起来像按钮压在边框上；悬停时红色背景几乎贴到圆角。问题截图来自 125% 缩放下的总览页。

**原因。** 窗口按钮画在内容页里的标题栏中：`ui/lib/src/shell/page_frame.dart` 的 `_TitleBar` 右侧只留 8 px，`ui/lib/src/shell/window_chrome.dart` 的 `_CaptionButton` 为 44 × 36、圆角 10、Material 图标 15 px。按截图量算，按钮并未越过圆角，问题在留白太小、图形风格不一致。

| 项 | 现状 | 修正 | 代码位置 |
| --- | --- | --- | --- |
| 按钮右侧留白 | 8 px | 16 px（有窗口按钮时） | `page_frame.dart` · `_TitleBar` |
| 与主按钮间距 | 10 px | 16 px | `page_frame.dart` · `_TitleBar` |
| 按钮尺寸与圆角 | 44 × 36，圆角 10 | 46 × 32，圆角 6，在 58 px 标题栏中垂直居中 | `window_chrome.dart` · `_CaptionButton` |
| 图形 | Material Icons 15 px | 自绘 10 px、1 px 线，按设备像素对齐 | `window_chrome.dart` · `CaptionButtons` |

**验收。** 在 100%、125%、150% 缩放下，分别截取最大化和还原两种窗口状态的右上角。悬停关闭按钮时，红色背景与内容页边缘至少隔 16 px。实现时若发现还有别的重叠（例如最大化时窗口超出屏幕边缘），补在这里。对照图见设计稿“待修 · 标题栏窗口按钮与内容页边缘重叠”画板；远程桌面设计稿的标题栏已按修正后的尺寸画。

**后续修改（2026-11-08，所有者复核后）。** 上面的修法仍把按钮放在一张浮在窗口底色上的圆角内容页里，看起来是两层，不像 Windows 自己的三个按钮。现改为：在 Windows 和 Linux 上，内容页贴住窗口的上、右、下三边，只在靠侧栏的左上角保留圆角和边线；三个按钮为 46 × 32 的直角方块，贴在窗口右上角，悬停底色铺到两条边，关闭的红色一直到角上（圆角由 Windows 自己裁）；查看器的按钮填满它 36 px 的标题栏；首次设置页的按钮也在同一个角。macOS 和宽屏平板仍用内缩的浮动内容页。上表和验收条件以此为准。

## 需要新增的能力

设计稿用到了以下能力，它们在 PR #51（`a41eaa7`）里还不存在。

| 能力 | 用在哪里 | 说明 |
| --- | --- | --- |
| 邀请二维码 | 主机卡片 | 点“二维码”才显示，离开页面即隐藏；只显示在本机屏幕上 |
| 相机扫码 | 手机添加电脑 | 需要相机权限和扫码库；画面不保存、不上传 |
| 手机加密保存邀请 | 远程电脑列表 | 现在只有 Windows 的 DPAPI；Android 用 Keystore，由“记住此电脑”开关控制 |
| 远程电脑在线状态 | 远程电脑列表 | 向中继查询对应服务是否已注册 |
| 上次画面缩略图 | 手机远程列表 | 断开时截取一帧，只存在本机，移除电脑时一并删除 |
| 主机查看者信息 | 主机卡片 | 显示是否有人在看、是否在控制、走直连还是中继、已连接多久 |
| 连接质量浮层 | 两端查看器 | 路径、网络往返、画面延迟、显示帧率、码率、分辨率、编码；口径与性能文档的测量一致 |
| 画质偏好 | 桌面“显示”菜单 | 画质优先 / 平衡 / 流畅优先，对应性能文档 P0-2、P0-4 的码率与帧率目标 |
| 工具栏固定与收起 | 桌面查看器 | 未固定时鼠标离开 2 秒收起成顶部把手 |
| 快捷键菜单与修饰键条 | 两端查看器 | 现在只映射部分按键（`desktop_viewer.dart` 的 `_keyNames`），要补齐 F1–F12、Home / End、Win 组合和可锁定的修饰键 |
| 新手势与虚拟鼠标 | 手机查看器 | 长按右键、轻点两下按住拖拽、三指滚动；直接触摸时可选虚拟鼠标 |

“Ctrl + Alt + Del”继续显示为暂不支持，与现有安全边界一致。
